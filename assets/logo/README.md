# ovdb logo

The logo is raster artwork; `ovdb-logo.png` is the master. There is no vector
version of the whole logo. Only the branch symbol on the door exists as SVG.

| File | Use |
|---|---|
| `ovdb-logo.png` | Master, 1254 px, transparent outside the ring. Make other sizes from this. |
| `ovdb-logo-512.png` | 512 px, transparent. Shown in the repository README. |
| `ovdb-logo-256.png` | 256 px, transparent. |
| `ovdb-logo-square.png` | Master on a white square, for places that cannot show transparency. |
| `ovdb-logo-square.jpg` | The same as JPEG, 1254 px. |
| `ovdb-logo-square-512.jpg` | The same as JPEG, 512 px. |
| `ovdb-logo-symbol.svg` | The branch symbol alone, in the master's pixel coordinates. |

The symbol is drawn flat and placed in the door's plane by the one matrix in
the SVG, so its dots are ellipses that match the light disc they sit on.
